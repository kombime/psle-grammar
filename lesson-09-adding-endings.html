Double It, Drop It, or Leave It?

Endings that start with a vowel, like -ing, -ed, -er and -able, are pushy. They lean on the vowel in front of them and try to make it "say its name". Hop + ing becomes "hoping", which sounds like hope! Your job is to keep the word's sound the same. You can build a wall of two letters, drop a silent e, or leave the word alone.

1. Pick a word.

2. Choose what to do before adding the ending.

The three-tile check

Ask these questions in order. Stop as soon as one gives you the answer.

1

Does the ending start with a vowel? If it starts with a consonant (-ful, -ly, -less, -ness, -ment), it isn't pushy. Just add it. Nothing changes.

hope + ful = hopeful · sad + ness = sadness · sincere + ly = sincerely

2

Does the word end in a silent e? Drop the e, then add the ending. Never double.

hope → hoping · write → writing · come → coming

3

Does it end in one short vowel + one consonant? Double the last letter to build a wall. If not, leave the word alone.

wrap → wrapped · stop → stopping · but jump → jumped, rain → raining

Why it works: say the word with and without the wall.

hop+ ing → "hoping" sounds like hope. ✗   "hopping" keeps the short o. ✓

A silent e is already there to make the vowel long, as in hope and write. When the ending arrives, its vowel takes over that job, so the e can step out.

Three traps

All three come straight from real compositions.

Trap 1: Doubling after a silent-e word

comming → coming   writting → writing   dinning → dining

Come, write and dine all end in a silent e. Silent-e words only drop the e. They never double. (Also, "dinning" comes from din, a loud noise!)

Trap 2: Forgetting the wall

wraped → wrapped   stoped → stopped   unforgetable → unforgettable

Read the wrong spelling aloud. "Wraped" would rhyme with "draped". One short vowel + one consonant needs two letters to protect its sound.

Trap 3: Dropping the e before a consonant ending

sincerly → sincerely   excitment → excitement   carful → careful

The e only drops for a vowel ending. -ly, -ment and -ful start with consonants, so they aren't pushy, and the e stays. This matters for every letter you sign "Yours sincerely".

The four tile racks

Every word you add an ending to belongs on one of these racks.

Double it

One short vowel + one consonant, with a vowel ending.

  • wrap → wrapped
  • run → running
  • swim → swimmer
  • big → biggest
  • plan → planned
  • hug → hugged
  • fun → funny
  • shop → shopping

Drop the e

Silent e, with a vowel ending.

  • come → coming
  • write → writing
  • dine → dining
  • smile → smiled
  • bake → baker
  • decide → decided
  • excite → exciting
  • nice → nicest

Leave it alone

The vowel is already protected by two consonants (jump) or two vowels (rain). Or the ending starts with a consonant.

  • jump → jumped
  • help → helper
  • rain → raining
  • look → looked
  • hope → hopeful
  • care → careless
  • excite → excitement
  • sad → sadly

Longer words: listen for the beat

Double only if the beat (stress) falls on the last part of the word.

  • forGET → forgettable
  • VISit → visited
  • beGIN → beginning
  • Open → opening
  • preFER → preferred
  • LISten → listening
  • adMIT → admitted
  • HAPpen → happened

Three special cases

The quiz checks these too.

Endings at the front (prefixes) never change anything

When you add dis-, mis- or un-, just join the two parts. Keep every letter of both.

dis + appear = disappear  (not dissappear or disapear)

mis + spell = misspell · un + necessary = unnecessary

The double s in "misspell" and the double n in "unnecessary" come from joining two parts. They aren't walls.

w, x and y never double

Even after one short vowel, these letters stay single.

snow → snowing · fix → fixed · box → boxer · play → played

The British "l" rule

In British spelling, which Singapore uses, a word ending in one vowel + l doubles the l, even when the beat comes first.

travel → travelled · cancel → cancelled · label → labelled · quarrel → quarrelled

American spelling writes "traveled". In PSLE, use the British form, just like centre, flavour and practised.

Pin This Up

  • Consonant ending (-ful, -ly, -less, -ment): just add it. sincere → sincerely.
  • Silent e + vowel ending: drop the e, never double. come → coming.
  • One short vowel + one consonant: double it. wrap → wrapped.
  • Longer words: double only if the beat is at the end. forget → forgettable, visit → visited.
  • Prefixes just join. w, x, y never double. British l doubles: travelled.
